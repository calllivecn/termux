这个传感器列表来自一套非常经典且成熟的硬件组合。与你之前的设备相比，它的命名更加规范（采用 `传感器类型-芯片型号` 的格式），这让底层调试变得更直观。

以下是该设备传感器的详细分类说明：

### 1. 基础运动与姿态 (由 LSM6DS3-C 驱动)

**LSM6DS3-C** 是意法半导体 (ST) 非常流行的惯性测量单元 (IMU)。

* **accelerometer-lsm6ds3-c**: 加速度计。测量三轴加速度，负责感应重力、摇晃和设备运动。
* **gyroscope-lsm6ds3-c**: 陀螺仪。测量角速度（每秒旋转的角度），是精准追踪旋转动作的核心。
* **uncalibrated Gyroscope**: 未校准陀螺仪。输出芯片的原始数据，不包含系统自动修正的零偏漂移，适合需要自行编写融合算法的高级用户。

### 2. 磁场与方位 (由 AKM09918 驱动)

**AKM09918** 是旭化成 (AKM) 的高精度电子指南针芯片。

* **akm-akm09918**: 磁力计。检测地球磁场，为导航软件提供方向。
* **uncalibrated Magnetic Field**: 未校准磁力计。不受系统干扰补偿影响的原始磁场数据。
* **orientation**: 方向传感器。这是一个软件合成传感器，直接给出方位角（Azimuth）、俯仰角（Pitch）和滚动角（Roll）。

### 3. 环境光与接近感应 (由 LTR578 驱动)

**LTR-578** 是 Lite-On（光宝）出品的二合一环境光与接近感应模组。

* **light-ltr578**: 环境光传感器。检测光照强度（Lux），用于自动调节屏幕亮度。
* **proximity-ltr578**: 接近传感器。通话时检测耳朵是否贴近手机，防止误触。

### 4. 虚拟/合成传感器 (Software Fusion)

这些传感器没有独立的物理实体，是 Android 系统利用上面几个芯片的数据计算出来的：

* **gravity**: 重力感应器。从加速度中分离出来的恒定重力分量。
* **linear Acceleration**: 线性加速度。剔除了重力影响后的纯运动加速度。
* **rotation Vector**: 旋转矢量。融合了加速度、陀螺仪和磁力计的最强姿态数据。
* **game Rotation Vector**: 游戏旋转矢量。只融合加速度和陀螺仪，不参考磁场，避免在室内磁场干扰下发生方向“漂移”。
* **geomagnetic Rotation Vector**: 地磁旋转矢量。类似于旋转矢量，但在没有陀螺仪或低功耗模式下主要依靠加速度和磁力计。

### 5. 行为与特殊触发器 (Trigger Sensors)

* **significant Motion**: 显著运动检测。一个极低功耗的触发器，当检测到用户在持续运动（如步行或乘车）时唤醒系统。
* **step counter**: 步数计数器。记录自开机以来的总步行步数。
* **HALL sensor**: 霍尔传感器。检测磁场变化，通常用于感知**翻盖皮套**的开合。
* **drop sensor**: 跌落传感器。专门优化过的算法，当手机处于失重状态（坠落）时迅速触发，通常用于保护硬盘（老手机）或在收缩弹出式摄像头。
* **phonecall sensor / RPC sensor**:
* **phonecall**: 专门为通话状态优化的感应逻辑。
* **RPC (Remote Procedure Call)**: 可能是系统底层用于跨进程通信的状态传感器，通常非开发人员很少直接调用。

### 💡 针对这台机器的脚本建议

这台机器拥有 **HALL sensor**，你可以写一个非常有趣的自动化脚本：

```bash
# 检测霍尔传感器（如果你的手机有磁吸皮套）
termux-sensor -s "HALL sensor" -d 500

```

如果你在手机边上放一块小磁铁，这个传感器的数值会发生剧烈变化。你可以利用它实现：**当磁吸皮套盖上时，Python 脚本自动停止所有后台采集任务，打开时自动恢复。**

## `termux-sensor -s "light-ltr578" -d 1000` 为什么是 3 个值？

```text
虽然不同的驱动实现略有差异，但对于 LTR578 芯片，这三个值通常代表以下含义：

Index 0: 综合环境光亮度 (Calculated Lux)

这是经过芯片算法融合后的最终数值。它是模拟人类肉眼感知的亮度。

单位：Lux。

Index 1: 全光谱通道 (Full Spectrum / CH0)

这是传感器感应到的所有光线，包括可见光和红外光。

用途：反映环境光的总能量。

Index 2: 红外光通道 (Infrared / CH1)

专门测量红外线（IR）的强度。

用途：用于判断光源类型（例如：阳光含有大量红外线，而普通的 LED 灯红外线含量极低）。为什么是 3 个值？
```
