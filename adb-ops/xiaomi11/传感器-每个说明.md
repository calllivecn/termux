这份传感器列表非常全面，涵盖了现代智能手机中最先进的感知硬件（如 **LSM6DSO** 惯性组合和 **BMP285** 气压计）。

为了方便你作为开发者查阅，我将这些传感器按照**功能逻辑**进行了深度分类说明：

---

### 1. 核心运动与姿态 (IMU - 惯性测量单元)

这些是手机进行空间定位、游戏控制和防抖的基础。

* **lsm6dso Accelerometer**: 加速度计。测量 X/Y/Z 三轴加速度。用于检测设备倾斜、震动或自由落体。
* **lsm6dso Gyroscope**: 陀螺仪。测量设备绕三轴旋转的角速度。
* **Accelerometer / Gyroscope - Uncalibrated**: 未校准版本。返回硬件原始数据，不包含系统的偏置补偿，适合需要高频原始数据进行自研算法（如卡尔曼滤波）的场景。
* **gravity**: 重力感应器。从复合加速度中提取出的重力分量，指向地心。
* **linear_acceleration**: 线性加速度。剔除重力后的纯运动加速度（如手机在桌面上平移）。
* **Rotation Vector / Game Rotation Vector**: 旋转矢量。融合多轴数据后输出的四元数或欧拉角，反映设备精准的 3D 空间姿态。

### 2. 环境感知 (Environment)

* **TMD3719ALSPRX Ambient Light Sensor**: 光线感应器。检测环境亮度（单位：Lux）。
* **rohm_bu27030_back**: 后置光线感应器。通常位于相机模组附近，用于辅助拍照时的白平衡校准。
* **bosch_bmp285 Pressure Sensor**: 气压计。测量大气压力。常用于室内导航（判断楼层）或天气趋势监测。
* **Elliptic Proximity**: 距离感应器。由于是“Elliptic”品牌，这通常是一种**超声波/虚拟距离感应**，通过听筒发出人耳听不到的声音来检测遮挡。

### 3. 健康与行为监测 (Fitness & Activity)

* **step_counter**: 计步器。记录自设备上次重启以来的总步数（低功耗硬件实现）。
* **step_detector**: 步数检测器。每检测到用户走一步就触发一次，延迟极低。
* **activity_recognition / har**: 动作识别（Human Activity Recognition）。识别用户当前是在走路、跑步、骑车还是在交通工具上。
* **stationary_detect / motion_detect**: 静止/运动检测。判断设备是否完全静止。
* **sns_smd (Significant Motion Detector)**: 显著运动检测。检测到用户在走路等大幅度动作时触发，常用于唤醒系统。

### 4. 交互与快捷手势 (OEM/Gesture)

这些传感器多为厂商针对系统体验深度定制的逻辑触发器：

* **dbtap**: Double Tap，双击亮屏。
* **knuckle**: 指关节检测。用于识别指关节截屏或手势快捷键。
* **pickup**: 拿起手机检测。
* **screen_down**: 屏幕朝下检测。常用于翻转静音。
* **pocket_mode**: 口袋模式。通过光感和距离感应判断手机是否在口袋内，防止误触。
* **hand_detect / gesture_detect**: 简单的挥手或手掌掠过检测。

### 5. 通信与生物识别辅助 (System & SAR)

* **sar_detector / semtech_sx932x**: SAR (Specific Absorption Rate) 传感器。用于检测人体与手机天线的距离。当人贴近手机时，系统会自动降低射频发射功率以降低辐射。
* **fod (Fingerprint on Display)**: 屏下指纹辅助。检测手指是否按压在指纹区域。
* **Aod (Always On Display)**: 息屏显示状态感应。
* **3d_signature**: 可能是高阶生物识别（如 3D 人脸）的辅助数据通道。

### 6. 其他特殊接口

* **ak0991x Magnetometer**: 磁力计（指南针）。测量地球磁场强度。
* **sns_geomag_rv**: 地磁旋转矢量。在没有陀螺仪或低功耗场景下，仅靠加速度和磁力计计算方位。
* **ccd_tilt**: 倾斜检测。常用于抬手亮屏的触发逻辑。
* **NonUi**: 非 UI 交互类传感器，通常为后台系统逻辑服务。
* **eqm (External Query Manager)**: 系统底层查询接口。
* **Touch Sensor**: 触摸层原始状态反馈。

### 🎓 给高级用户的核心提示：

* **Wakeup vs Non-wakeup**:
* 带有 `Wakeup` 的传感器可以在手机**息屏/休眠**时唤醒系统（比如“拿起亮屏”）。
* `Non-wakeup` 只能在系统处于唤醒状态时上报数据，更省电。


* **数据调用**: 由于这些名称包含空格（如 `"step_counter  Wakeup"`），在 Python 脚本中调用时，请务必使用双引号包裹完整的字符串，否则 `termux-sensor` 会报错。
